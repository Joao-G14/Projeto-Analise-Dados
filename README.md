Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de realizar a análise de dados de produção industrial utilizando Python para tratamento dos dados e Power BI para visualização das informações.

A proposta do projeto é transformar dados brutos de produção em indicadores e gráficos que auxiliam no acompanhamento da operação e na tomada de decisão.

Tecnologias Utilizadas
Python
Pandas
Numpy
Power BI
Estrutura do Projeto
Produção.xlsx → Base de dados
produção.py → Script Python responsável pelo tratamento e análise dos dados
Dashboard.pbix → Dashboard desenvolvido no Power BI
Tratamento de Dados com Python

O tratamento dos dados foi realizado utilizando Pandas e Numpy.

O script realiza:

Leitura da base de dados
Tratamento de valores nulos
Conversão de datas
Classificação de registros produtivos e paradas
Criação de indicadores de produção
Agrupamentos por mês
Geração dos dados utilizados no Power BI
Indicadores Desenvolvidos

O projeto realiza o cálculo dos seguintes indicadores:

Total aprovado
Total rejeitado
Horas produtivas
Horas paradas
Disponibilidade
Qualidade
Produção aprovada por mês
Dashboard no Power BI

O dashboard foi desenvolvido para apresentar os principais indicadores da produção de forma visual e interativa.

O painel contém:

Cards com indicadores gerais
Gráfico de produção mensal
Indicador de disponibilidade
Indicador de qualidade
Filtros Interativos

O dashboard possui filtros por:

Operador
Mês

Ao selecionar um operador ou mês, todos os gráficos e indicadores são atualizados automaticamente, permitindo visualizar os dados específicos de cada operador e de cada período.

Objetivo do Projeto

O projeto foi desenvolvido para prática de:

Análise de dados
Tratamento de dados com Python
Desenvolvimento de KPIs
Visualização de dados
Criação de dashboards no Power BI
